# UART и интеграция со SCADA

## Подключение

Плата KP_24V только передаёт данные. Общие параметры: **9600 бод, 8N1**, текст ASCII, окончание строки **CRLF**.

- J5.2 UART_TX_OUT → RX внешнего приёмника с логикой 5 В.
- J5.1 GND → GND приёмника.
- Последовательный резистор 1 кОм уже предусмотрен на выходе Nano; на макете без этой цепи его устанавливают отдельно.
- Питания +5 В двух устройств не объединять автоматически; при подключённой линии обе стороны должны быть запитаны.
- Для приёмника с логикой 3,3 В необходимо согласование уровней.

Вывод D8 используется как RX в обоих описанных ниже внешних приёмниках. Не путать пины внешнего контроллера с пинами самой Nano.

## Формат

| Строка | Значение |
| --- | --- |
| `V:270` | Напряжение 27,0 В |
| `T:234` | Температура 23,4 °C |
| `T:-55` | Температура −5,5 °C |
| `T:32767` | Ошибка чтения DS18B20 |
| `C1:0` / `C2:0` | Контакт соответствующего ИБП замкнут, норма |
| `C1:1` / `C2:1` | Контакт разомкнут, авария или обрыв цепи |

V, C1 и C2 отправляются раз в 500 мс. T отправляется отдельно после завершения измерения датчиком. Порядок строк не является атомарным снимком всех каналов.

Контактная логика должна быть проверена на конкретном ИБП. Передавать на вход сухого контакта внешнее напряжение нельзя.

## Внешний приёмник определяет карту Modbus

У измерительной Nano нет собственных регистров Modbus. У двух использованных приёмников разные карты. Все адреса ниже **с нуля**, функция **FC04**.

| Данные | Стенд ScadaRelayTimer | ПАК plc-prs10 |
| --- | ---: | ---: |
| Напряжение KP_24V | 3 | 1 |
| Температура АКБ KP_24V | 4 | 2 |
| Авария ИБП 1 | 5 | 3 |
| Авария ИБП 2 | 6 | 4 |
| Маска достоверности KP_24V | нет | 5 |

В ПАК адрес 0 сохранён за его местным DS18B20. Контакты D2–D5 ПАК опрашиваются отдельно через FC02 и не являются контактами C1/C2 измерительной Nano.

Для ПАК: Modbus Poll → FC04, Address 0, Quantity 6. Для стенда: FC04, Address 0, Quantity 7. Адрес сервера определяется прошивкой соответствующего приёмника.

Температура — signed 16-bit; напряжение, контакты и маска — unsigned 16-bit. Напряжение и температуру делить на 10. В редакторе с адресацией «начиная с 1» к приведённым адресам прибавить 1.

## Достоверность

Приёмник ПАК использует независимый таймаут 5 с для каждого канала. Маска FC04/5:

- бит 0 (1): напряжение;
- бит 1 (2): температура АКБ;
- бит 2 (4): контакт ИБП 1;
- бит 3 (8): контакт ИБП 2.

15 = все данные актуальны. 13 = актуальны напряжение и контакты, температура недостоверна. 0 = нет актуальных данных.

32767 для температуры и 65535 для напряжения/контактов — коды ошибки, а не физические значения. Их нельзя отображать после обычного масштабирования.

Текущая Nano при потере DS18B20 может перестать отправлять T до перезапуска, поэтому факт прихода V/C1/C2 не подтверждает исправность температуры. Стендовый ScadaRelayTimer не следует считать эквивалентом ПАК по контролю свежести: в рассмотренной стендовой версии отсутствует такой поканальный таймаут.

## Ограничения протокола

Нет контрольной суммы, номера пакета и подтверждения доставки. Приёмник должен проверять формат, диапазоны и возраст данных. Одного наличия UART-трафика недостаточно для признания всех измерений достоверными.
